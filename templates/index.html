Overview

Why Richardson Extrapolation?

A systematic method for upgrading the accuracy of any finite-difference formula by exploiting its known error structure.

🎯

Error Cancellation

The weighted combination \( R = (4D(h/2) - D(h))/3 \) algebraically cancels the \(h^2\) term, leaving only an \(O(h^4)\) residual.

⚡

Minimal Cost

Only 4 function evaluations needed — the same operations required for two central-difference approximations at different step sizes.

📐

General Principle

Applicable to any approximation with an asymptotic error expansion in even powers of h. Foundation for Romberg integration, deferred-correction ODEs, and more.

🔬

Iterable

Apply Richardson again to the Richardson result — each level doubles the order of accuracy. The full 4×4 tableau achieves O(h⁸) with just 8 function evaluations.

Theory

Mathematical Discussion

Formal Taylor-series derivation, error analysis, second-derivative extension, and a comparison of advantages and limitations.

1. Numerical Differentiation and the Central-Difference Formula

Let \( f : \mathbb{R} \to \mathbb{R} \) be sufficiently smooth. The central-difference formula approximates \( f'(x) \) using two function evaluations symmetrically placed about \(x\):

\[ D(h) \;=\; \frac{f(x+h) - f(x-h)}{2h} \]

Expanding via Taylor's theorem around \(x\):

\[ f(x \pm h) = f(x) \pm h f'(x) + \frac{h^2}{2}f''(x) \pm \frac{h^3}{6}f'''(x) + \frac{h^4}{24}f^{(4)}(x) \pm \cdots \]

Subtracting and dividing by \(2h\) gives the exact expression:

\[ D(h) = f'(x) + \underbrace{\frac{h^2}{6}f'''(x)}_{c_2 h^2} + \underbrace{\frac{h^4}{120}f^{(5)}(x)}_{c_4 h^4} + \cdots \]

The error is purely even in \(h\): a crucial fact that Richardson exploits. The leading truncation error is \(O(h^2)\).

2. Richardson Extrapolation — Formal Derivation

Definition (L.F. Richardson, 1911)

Given two approximations at step sizes \(h\) and \(h/2\) each with error structure \( D(h) = f'(x) + c_2 h^2 + O(h^4) \), Richardson Extrapolation eliminates the \(h^2\) term by forming the weighted combination: \[ R(h) \;=\; \frac{4\,D(h/2) - D(h)}{3} \;=\; f'(x) + O(h^4) \]

Derivation: Replace \(h\) with \(h/2\) in the error expansion:

\[ D\!\left(\tfrac{h}{2}\right) = f'(x) + c_2\!\left(\tfrac{h}{2}\right)^{\!2} + O(h^4) = f'(x) + \tfrac{c_2 h^2}{4} + O(h^4) \]

Multiply by 4 and subtract \(D(h)\):

\[ 4D\!\left(\tfrac{h}{2}\right) - D(h) = 4\!\left[f'(x) + \tfrac{c_2 h^2}{4}\right] - \left[f'(x) + c_2 h^2\right] + O(h^4) = 3\,f'(x) + O(h^4) \]
\[ \boxed{R(h) = \frac{4\,D(h/2) - D(h)}{3} = f'(x) + O(h^4)} \]

3. Richardson Tableau — Higher-Order Extrapolation

The process can be iterated. Define the tableau entries \(D_{i,j}\) where column 0 contains central differences at decreasing step sizes and each subsequent column eliminates one more error term:

\[ D_{i,\,j} \;=\; \frac{4^j\,D_{i,\,j-1} - D_{i-1,\,j-1}}{4^j - 1}, \quad j \geq 1,\; i \geq j \]

Column \(j\) has error \(O(h^{2(j+1)})\). A \(4\times 4\) tableau therefore achieves \(O(h^8)\) accuracy — comparable to 8th-order Runge–Kutta — from only 4 central-difference evaluations.

4. Second Derivative via Richardson Extrapolation

The second-order central-difference for \(f''(x)\) is:

\[ D_2(h) = \frac{f(x+h) - 2f(x) + f(x-h)}{h^2}, \quad \text{error } O(h^2) \]

Applying Richardson gives \(O(h^4)\) accuracy for \(f''(x)\):

\[ R_2(h) = \frac{4\,D_2(h/2) - D_2(h)}{3} = f''(x) + O(h^4) \]

5. Optimal Step Size

The total error has two competing contributions: truncation error (\(\propto h^4\)) which decreases as \(h \to 0\), and rounding error (\(\propto \varepsilon_{\text{mach}} / h\)) which grows. The optimal step for Richardson is approximately:

\[ h_{\text{opt}} \;\approx\; \varepsilon_{\text{mach}}^{1/4} \;\approx\; 1.2 \times 10^{-4} \]

where \(\varepsilon_{\text{mach}} \approx 2.2 \times 10^{-16}\) for 64-bit IEEE double precision. The calculator automatically recommends a near-optimal step size.

6. Numerical Stability and Catastrophic Cancellation

When \(h\) is too small, the subtraction \(f(x+h) - f(x-h)\) may lose all significant digits (\emph{catastrophic cancellation}). As a rule of thumb:

\[ \text{Lost digits} \;\approx\; \log_{10}\!\left(\frac{\max(|f(x+h)|,|f(x-h)|)}{|f(x+h)-f(x-h)|}\right) \]

The calculator detects this condition and warns the user. Avoid step sizes below \(h \approx 10^{-8}\) for typical double-precision computation.

7. Advantages and Limitations

✓ Advantages

  • Raises accuracy from O(h²) to O(h⁴) with 0 extra evaluations
  • Full tableau achieves O(h⁸) cheaply
  • No analytic derivative required
  • Self-contained error estimate via tableau differences
  • Extends to higher derivatives naturally
  • Foundation for Romberg integration

✗ Limitations

  • Requires smooth (C∞) functions
  • Rounding error grows as h → 0
  • Not suitable for noisy or tabulated data
  • Singularities invalidate Taylor expansion
  • Step-size selection requires judgment
  • Complex arithmetic not handled by basic formula

Worked Examples

Two Complete Step-by-Step Solutions

All intermediate values shown explicitly. Verify these results using the interactive calculator below.

1

f(x) = sin(x) at x₀ = 1.0, h = 0.1

Exact derivative: f′(x) = cos(x) ⟹ f′(1.0) = cos(1.0) ≈ 0.54030

Given

\[f(x) = \sin(x),\quad x_0 = 1.0,\quad h = 0.1\] \[f'(x) = \cos(x) \;\Rightarrow\; f'(1.0) = \cos(1) \approx 0.54030\]
Step 1 — Function evaluations
\[f(1.1) = \sin(1.1) \approx 0.89121\] \[f(0.9) = \sin(0.9) \approx 0.78333\] \[f(1.05) = \sin(1.05) \approx 0.86742\] \[f(0.95) = \sin(0.95) \approx 0.81342\]
Step 2 — Central difference D(h) with h = 0.1
\[D(0.1) = \frac{f(1.1) - f(0.9)}{2(0.1)} = \frac{0.89121 - 0.78333}{0.2} = \frac{0.10788}{0.2} = \mathbf{0.53940}\] \[\text{Truncation error} = \left|\,D(0.1) - f'(1)\right| \approx 9.00 \times 10^{-4}\]
Step 3 — Central difference D(h/2) with h/2 = 0.05
\[D(0.05) = \frac{f(1.05) - f(0.95)}{2(0.05)} = \frac{0.86742 - 0.81342}{0.1} = \frac{0.05401}{0.1} = \mathbf{0.54008}\]
Step 4 — Richardson Extrapolation
\[R = \frac{4 \times D(0.05) - D(0.1)}{3} = \frac{4 \times 0.54008 - 0.53940}{3} = \frac{2.16031 - 0.53940}{3} = \frac{1.62091}{3} \approx \mathbf{0.54030}\]
Results Summary

Richardson result: \(R \approx 0.54030\)

Exact \(f'(1) = \cos(1) \approx 0.54030\)

Richardson error: \(|R - f'| \approx 4.0 \times 10^{-7}\)

Central-diff error: \(|D(h) - f'| \approx 9.0 \times 10^{-4}\)  →  Richardson is ≈ 2 250× more accurate

The improvement factor is \(h^2 / h^4 = 10^2 = 100\) in theory; the measured 2 250× reflects the specific Taylor coefficients of \(\sin(x)\) at \(x=1\).

2

f(x) = x³ − 2x + 1 at x₀ = 2.0, h = 0.2

Exact derivative: f′(x) = 3x² − 2 ⟹ f′(2.0) = 10.0 (integer, exact)

Given

\[f(x) = x^3 - 2x + 1,\quad x_0 = 2.0,\quad h = 0.2\] \[f'(x) = 3x^2 - 2 \;\Rightarrow\; f'(2) = 3(4) - 2 = 10\]
Step 1 — Function evaluations
\[f(2.2) = (2.2)^3 - 2(2.2) + 1 = 10.648 - 4.4 + 1 = \mathbf{7.248}\] \[f(1.8) = (1.8)^3 - 2(1.8) + 1 = 5.832 - 3.6 + 1 = \mathbf{3.232}\] \[f(2.1) = (2.1)^3 - 2(2.1) + 1 = 9.261 - 4.2 + 1 = \mathbf{6.061}\] \[f(1.9) = (1.9)^3 - 2(1.9) + 1 = 6.859 - 3.8 + 1 = \mathbf{4.059}\]
Step 2 — Central difference D(h) with h = 0.2
\[D(0.2) = \frac{7.248 - 3.232}{2(0.2)} = \frac{4.016}{0.4} = \mathbf{10.04}\] \[\text{Truncation error} = |10.04 - 10| = 0.04\]
Step 3 — Central difference D(h/2) with h/2 = 0.1
\[D(0.1) = \frac{6.061 - 4.059}{2(0.1)} = \frac{2.002}{0.2} = \mathbf{10.01}\]
Step 4 — Richardson Extrapolation
\[R = \frac{4(10.01) - 10.04}{3} = \frac{40.04 - 10.04}{3} = \frac{30.00}{3} = \mathbf{10.00}\]
Why is Richardson exact here?

For \(f(x) = x^3 - 2x + 1\), the 4th derivative \(f^{(4)}(x) = 0\) identically. This means the Taylor error expansion terminates after the \(h^2\) term, which Richardson eliminates exactly. The result is \(f'(2) = 10.000\ldots\) to machine precision.

\[D(h) = f'(x) + \frac{h^2}{6}f'''(x) + \underbrace{O(h^4)}_{=\,0 \text{ for cubics}} \quad\Rightarrow\quad R = f'(x) \text{ exactly}\]
Results Summary

Richardson result: \(R = 10.00000\ldots\) (machine precision)

Exact \(f'(2) = 10.0\)

Richardson error: \(|R - f'| \approx 7 \times 10^{-15}\) (rounding only)

Central-diff error: \(|D(h) - f'| = 0.04\)

Richardson is exact for polynomials of degree ≤ 3. This confirms the theoretical prediction that the \(h^2\) cancellation is algebraically perfect.
